# 🚀 Queue Management & Audit System

A web-based system developed for real-time monitoring and management of internal service queues, featuring role-based access control for employees and managers.

## 🛠️ Tech Stack

- **Front-end:** HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Back-end:** Python 3.x, FastAPI
- **Database:** MySQL
- **Authentication:** JWT (JSON Web Tokens)

## 📌 Key Features

- **Employee Module:**
  - Real-time queue visualization.
  - Options to join and leave the queue.
- **Manager Module:**
  - Administrative panel for queue reset and clear-all actions.
  - Audit module with detailed action logs (who called, timestamp, and changes made).
  - Role-based access control and user management.
